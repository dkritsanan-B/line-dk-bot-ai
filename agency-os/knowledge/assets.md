# 🔗 ช่องทางติดต่อ & แหล่งรูป — DK Steel

> ⚠️ **ข้อมูลติดต่อจริง + รูปสินค้า ย้ายไป Supabase/B2 แล้ว** — ดึงสดผ่าน API ดู [[data-source]]
> - ช่องทางติดต่อ → field `contact` ใน `/api/catalog` (ตาราง `contact_info`)
> - รูปสินค้า → field `image_url` ของแต่ละสินค้า (ลิงก์ชั่วคราวจาก B2)
>
> ไฟล์นี้เก็บแค่ **แนวทาง** ที่ไม่เปลี่ยน (ไม่ใช่ตัวข้อมูล)

---

## 📞 กฎการใส่ช่องทางติดต่อ
- 💬 ดัน **LINE เป็นช่องทางหลัก** เสมอ (ปุ่ม "ทัก LINE" ท้ายทุกโพสต์)
- ดึงค่า LINE/เพจ/เบอร์ จาก `contact` ใน API — ถ้ายังว่างให้เตือนเจ้าของร้านไปเติมก่อนยิงแอด

## 🎨 แนวทางภาพลักษณ์ (ไว้ใช้ตอนทำรูป AI)
- โทนอุตสาหกรรม/งานช่าง — เหล็ก, โลหะ, สีเข้ม + สีส้ม/เหลืองตัดให้เด่น
- ดูน่าเชื่อถือ แข็งแรง ไม่หวือหวาเกินจริง
