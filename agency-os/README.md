# 🏢 DK Steel — Agency OS

## ▶️ วิธีสั่งงาน (สำหรับเจ้าของร้าน)

พิมพ์บอก Claude ด้วยภาษาพูดปกติ เช่น:

- **"เริ่มแคมเปญใหม่ — อยากจัดโปรเหล็กกล่องหน้าฝน งบ 5,000"**
- **"ขอแผนคอนเทนต์เดือนนี้ เน้นเครื่องมือช่าง"**
- **"ช่วยคิดโพสต์โปรเมทัลชีท 3 โพสต์"**
- **"สรุปผลโฆษณาที่ยิงไปให้หน่อย"**

Claude จะเดินสายพาน 6 แผนกให้อัตโนมัติ และหยุดถามคุณเมื่อต้องตัดสินใจ

---

## 🔗 สายพานการทำงาน (6 แผนก)

```
1. Campaign  📌 รับโจทย์ → ตั้งเป้าหมาย งบ ระยะเวลา
        ↓
2. Strategy  🎯 วางกลยุทธ์ + Big Idea
        ↓
3. Content   ✍️ วางแผนคอนเทนต์ (โพสต์อะไรบ้าง)
        ↓
4. Production 🎨 ผลิตรูป/วิดีโอ + แคปชัน
        ↓
5. Media     📢 ตั้งค่า + ยิงโฆษณา Facebook
        ↓
6. Analyze   📊 วิเคราะห์ผล → เสนอปรับปรุง → วนกลับข้อ 1
```

---

## 📌 กฎเหล็กของระบบ (ทุกแผนกต้องยึด)

1. **อ่าน `brand-brief.md` ก่อนทำงานทุกครั้ง**
2. **ชูเหล็ก + เครื่องมือช่าง + เมทัลชีท เป็นหลัก** ไม่ไปแข่งของตกแต่ง/อิฐหินปูนทราย
3. **ไม่โอ้อวดเกินจริง · ไม่โจมตีคู่แข่งแรง ๆ**
4. **ลงราคาเฉพาะช่วงโปรโมชัน** พร้อมระบุระยะเวลาชัดเจน
5. **ดันให้ลูกค้าทัก LINE เป็นช่องทางหลัก**
