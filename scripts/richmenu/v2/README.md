# DK Rich Menu v2

- **A — Premium Steel:** พื้นน้ำเงินกรมท่าผืนเดียว เส้นสายแบบงานเหล็ก และกรอบเหลือง เน้นบัตรสมาชิกขนาดใหญ่ เหมาะกับภาพลักษณ์ร้านมืออาชีพและงานโครงการ
- **B — Clean Cards:** พื้นขาวฟ้า การ์ดมุมมน ไอคอนเส้นหนา และแถบสมาชิกสีเหลืองเต็มด้านบน เหมาะกับลูกค้าที่ต้องการเมนูอ่านง่าย สบายตา และคุ้นเคยทันที
- **C — Workshop Safety:** ผิวเหล็กเข้ม ป้ายหมายเลข และแถบเตือนเหลืองดำ เน้นตัวอักษรหนา เหมาะกับภาพลักษณ์หน้าร้านช่างที่แข็งแรง จำง่าย และสะดุดตา

เรนเดอร์ใหม่ด้วย `node scripts/richmenu/v2/render.mjs` ผลลัพธ์อยู่ใน `v2/out/` โดยไฟล์ `*-phone.png` คือภาพจำลองการย่อบนหน้าจอ LINE กว้าง 400px
